DUCK Stealth Framework

Platform: Windows 10/11 Build: NativeAOT Engine: C++ / ASM

DUCK Stealth — a modular framework for covert data collection and remote management on Windows. The system is designed with a Zero-Disk Presence architecture, minimizing artifacts on the target system and evading behavioral analysis of modern EDR/AV solutions.

🏗 System Architecture

The framework is a hybrid system consisting of a C# management core and a native C++/Assembly execution layer.

  • Main Controller (C# NativeAOT): The core bot. The entire project compiles directly to x64 machine code, eliminating MSIL. Analysis requires IDA Pro/Ghidra. Utilizes an asynchronous Task model.
  • Elevator Core (C++): The native injection core. Uses Reflective Manual Mapping for loading into memory without LoadLibrary, and Direct Syscalls to invoke OS kernel functions, bypassing usermode hooks.

👻 Stealth Collection Tech

  • Zero-Disk Extraction (In-Memory Streaming): Data is never written to %TEMP%. The bot opens a Named Pipe tunnel, and the native core streams data directly from memory. Final transmission occurs via encrypted MemoryStream.
  • Handle Duplication: To read locked database files (e.g., browser Cookies), the framework duplicates the process handle via NtDuplicateObject, avoiding suspicious process termination.

🛡 Evasion Mechanisms

  • Dynamic SSN Resolution: Parses ntdll.dll on disk/in memory to find System Service Numbers (SSN) and invokes them via syscall.
  • Anti-Analysis: RDTSC timing checks to detect emulation/sandboxes. Hardware breakpoint checks for DR0-DR7.
  • x64 Stack Alignment: Strict x64 ABI compliance during reflective loading (32-byte Shadow Space, 16-byte alignment) for stability without BSODs.

🔌 IPC Protocol

Communication between the browser core and the controller via asynchronous Named Pipes with restricted ACLs to prevent interception.
